# 交互式CLI使用手册

推荐普通用户使用本页。首次安装见[项目README](../../README.md)，完整配置见[运行规则](../03-设计文档.md)。

## 启动和恢复

```powershell
uv run --locked future-agent chat
uv run --locked future-agent chat --resume <会话ID>
```

启动后输入事件描述；已有会话时可以按编号选择。输入为单行，较长描述可分次补充。`/help`随时显示操作表，`/exit`退出。

恢复只展示保存状态，不自动重发请求。使用其他数据目录时需保持相同配置，例如：

```powershell
uv run --locked future-agent --no-env --data-dir data/my-analysis chat
```

`--no-env`禁用文件配置，仍读取进程环境变量；需要模型时须另有有效配置。

## 普通模式的一次分析

1. 保存叙述并允许在会话预算内使用模型，系统整理原文、拟定目标和假设。
2. 必要时一起提出最多三个问题。可一次回答，也可回车保留未知；整会话只有一轮额度。
3. 查看并授权公开查询。系统自动搜索、读取正文和摘录；补充的新查询单独请求授权。拒绝搜索则保留无检索限制。
4. 系统评估依据，形成判断。研究后直接回车跳过私人问题且输入仍有效时，会保留已有研究继续，不重新要求同一批查询授权。
5. 默认先显示结果概览：问题、期限、交付类型、主判断、依据、未知和改判条件；用`/details`查看各结果的完整推断、引用与版本信息。有数字不代表已校准；条件分析不代表有总体概率。
6. 用`/save`保存，按需`/freeze`冻结，未来用`/resolve`登记实际结果。

相对窗口安排在剩余生成预算之后，准确起止见报告；已开始的绝对窗口不能自动后移。目标仍无法定义时保存原因，不生成假报告。

## 命令表

| 命令 | 用途 |
|---|---|
| `/continue` | 继续当前分析 |
| `/status` | 查看目标、阶段、未知、缺口和剩余预算 |
| `/report` | 查看选中预测的结果概览 |
| `/details`、`/save` | 查看完整报告或导出完整报告 |
| `/history` | 选择历史预测 |
| `/answer` | 补充或纠正事实，旧预测保留 |
| `/read`、`/unknown`、`/target` | 手动重读、选择保留未知、编辑目标；通常无需操作 |
| `/research`、`/forecast` | 普通模式继续自动分析；人工模式分别研究/预测 |
| `/freeze`、`/resolve` | 冻结或另存修订、追加手动核验 |
| `/retry`、`/cancel` | 检查并恢复或取消中断步骤 |
| `/new`、`/select` | 新建或选择会话 |
| `/help`、`/exit` | 帮助、退出 |

“继续、状态、报告、保存、退出、帮助”可代替对应命令；其他文字作为描述或补充保存，不执行任意shell命令。在提示中输入`/status`、`/report`、`/details`、`/save`、`/help`后返回原输入，其他命令切换操作。

终端输出按分区留白，长文本按中文显示宽度换行；不依赖终端颜色。完整报告与导出保留全部已保存依据，查看概览或详情不会调用模型。

## 报告、冻结和核验

`/save`创建`DATA_DIR/reports/<随机ID>/`，写入UTF-8的`report.md`、`report.json`和完整写入后的`COMPLETE`标记。重复保存另建目录；不覆盖历史文件。没有COMPLETE表示导出未完成。

JSON是裁剪后的导出投影，不能作为完整Forecast重新导入。它不包含整段原始叙述、整页缓存或服务配置，但问题和引用仍可能有私人信息。格式说明见[数据与版本](../reference/数据与版本.md)。

冻结保存完整快照及哈希；修改必须另存预测。目标、窗口或核验规则变化须独立冻结，不能伪装为同一目标修订。核验状态为pending、resolved、disputed或void；未到完整窗口不能将暂未发生判为负例。提前核验只允许冻结时预先声明的发生结果，并仍须满足来源和时间规则。

## 失败与中断

- 运行时终端前台等待，不能并行输入命令；使用Ctrl+C中断，再恢复查看状态。
- 中断保留尝试和预算。`/retry`会说明结果/费用未知和可能重复计费，已完成步骤复用原产物。
- 搜索部分失败会保留缺口；故障且无判断依据时停在未完成状态，不编造预测。
- 预算耗尽后不能靠恢复重置，已有报告仍可查看和保存。
- 模型配置与搜索/正文服务分别检查，不通过关闭公网/TLS检查解决抓取问题。

## 高级人工模式

```powershell
uv run --locked future-agent chat --manual
```

此模式用于逐项核对档案、目标、引用相关性和结果定义。需要人工填写含时区时间、选择精确引文并确认；默认情景，申请数字仍须通过资格检查。它不是普通模式必须经过的步骤。

脚本和实验操作见[分步CLI](分步CLI.md)。当前只有本地单用户前台终端，没有后台任务、自动监测或会话删除功能。
