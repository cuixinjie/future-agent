# 本地Web界面使用手册

界面是本机浏览器的另一个交互入口，不是公开服务。分析与数据仍由现有应用服务执行，写入同一个 `DATA_DIR`。

## 启动

```powershell
uv run --locked future-agent web
```

默认只监听 `127.0.0.1:8765` 并尝试打开浏览器。常用参数：

```powershell
uv run --locked future-agent web --port 9000
uv run --locked future-agent web --no-browser
uv run --locked future-agent --data-dir data/my-analysis web
```

`--host` 只接受本机回环地址；不提供远程访问、登录或多人隔离。启动前先运行 `future-agent doctor` 检查配置。

## 一次分析

1. 在左侧点“新预测”，输入事实并提交。配置了模型时会立即整理目标；模型未配置时只保存原文，之后可在会话里点“整理目标”。
2. 查看系统拟定的问题、结果、期限、核验规则和假设。目标可用时点“开始分析”；需要澄清时回答或提交未知，整会话仍只有一轮澄清。
3. 需要公开搜索时勾选“允许检索公开网页”；不授权则按无检索继续，不使用模拟网页。
4. 分析在后台线程执行，页面显示当前阶段、模型调用等待及有限重试/格式修复进度。最终预测阶段可点“停止最终判断”：当前请求返回或超时后结束，丢弃迟到结果，仍可能计费；研究与阅读阶段暂不支持整任务停止。完成后查看主判断、各结果推断、引用、未知、改判条件和限制。
5. 可打开原始报告、复制报告或导出到 `DATA_DIR/reports/`；导出前可冻结。冻结不可覆盖，新判断用“另存修订”。
6. 有实际结果后，在“核验”中登记结局、来源和说明；需要时使用默认值 `pending` 并填写原因。

会话列表按创建时间显示状态和阶段。刷新或重新打开会话会自动重连本进程中的任务；进程重启后，中断步骤通过“重试”恢复。重试需确认未知费用和可能重复计费，不重置预算。浏览器断网后可重新打开会话连接进度。

会话页可删除原文、补充、分析和数据库报告。运行中任务必须先完成；中断步骤须先处理。冻结预测及关联实验的会话拒绝删除。已导出的报告文件和共享正文快照保留，不进行自动文件清理。

Web 与 CLI 使用同一个配置及 SQLite 数据目录，重启后仍能读取记录。这是会话持久化；当前没有跨会话自动检索记忆、用户画像或长期记忆注入。更换工作目录、`--env-file` 或 `--data-dir` 可能切换配置与历史库。

“模型已配置”只表示配置齐全，不表示真实生成通过。`invalid_output` 是返回内容未通过程序校验，`incomplete_output` 是输出未完整结束，`network` / `timeout` 是连接或超时故障。中断的 `READING` / `FORECASTING` 状态需要显式重试。

## 边界

- 界面不隐藏失败：模型未配置、预算不足、搜索失败或引用审查失败都会直接显示，不伪装成预测成功。
- 主观概率未独立校准，方向判断、条件概率和情景都不能当作总体概率。
- 不要使用公网反向代理暴露本服务；没有认证、限流或多用户隔离。
- 报告可能包含私人问题、未知和引用，公开前自行检查。

接口路径、阶段名称和页面脚本位于 `src/future_agent/web/`，如只需命令行，见[交互式CLI](交互式CLI.md)。
