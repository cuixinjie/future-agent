# 0.1.0a1 · Alpha 实验版

> 本文记录2026-10-28发布时的状态。当前分支功能及后续修复请看[项目README](../../README.md)和[变更日志](../../CHANGELOG.md)。

这是预测未来智能体的首个 GitHub 预发布版本，面向本地试用、开发和实验准备。源码公开，暂未授予开源许可证。它不是已验证预测效果的正式版，也没有执行真实前瞻实验。

## 主要能力

- 普通 CLI 自动整理目标、最多一轮三个澄清问题、经授权进行有界公开研究与精确引用。
- 支持主观概率、方向判断、条件分析、未来探索及无法判断，分别保存交付类型和执行状态。
- 会话及预算持久化、中断恢复、Markdown/JSON 导出、预测冻结、另存修订及手动核验。
- 新版独立 Schema 2.0 实验适配，比较 A/B/C 三组，保留旧协议、旧快照与冻结哈希。

## 安装

需要 Git、uv 和 Python 3.12，优先按已验证的 Windows PowerShell 路径使用：

```powershell
git clone https://github.com/cuixinjie/future-agent.git
cd future-agent
git checkout v0.1.0a1
uv sync --locked
if (-not (Test-Path -LiteralPath .env)) { Copy-Item -LiteralPath .env.example -Destination .env }
# 编辑 .env，配置真实模型服务；搜索另行配置
uv run --locked future-agent doctor
uv run --locked future-agent chat
```

`doctor` 默认只检查本地配置；`doctor --live` 会产生最多两次真实模型请求。实际分析也可能产生费用；价格未知时不会给出精确金额。叙述、回答和分析资料会发送至配置的模型，公开查询经授权发送至独立搜索服务。凭据及私人数据不要提交到仓库。

搜索部署见 [SearXNG 说明](../../deploy/searxng/README.md)，完整使用见 [交互式 CLI](../guides/交互式CLI.md)。不联网的固定夹具演示：`uv run --locked python examples/m1_offline.py`；该演示不产生真实预测。
