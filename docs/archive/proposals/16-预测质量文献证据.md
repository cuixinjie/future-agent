# 预测质量补强：文献证据与公开评估资源

> 历史资料：保留编写时的实现、计划及验收结论，不作为当前使用说明。当前入口见 [文档导航](../../README.md)。

日期：2026-10-29。用途：为[预测质量架构补强](预测质量架构补强.md)选择机制。本文是原始研究的有限归纳，不是本项目复现实验报告；各论文的模型、题集和评分口径不同，不跨表比较绝对成绩。

## 1. 文献选择与证据等级

优先读取原作者论文、作者机构资料和数据发布方说明。区分：A＝预测任务直接实验；B＝其他任务的机制实验；C＝教材/理论或方法学分析。A也不代表结论能无条件迁移。下列分级是本项目审阅标签，不是论文质量评分。

| 原始来源与读取位置 | 专家已经验证或指出什么 | 可采用的机制及限制 |
|---|---|---|
| A：[Halawi等，2024，v1，第6–7节、表4–5](https://arxiv.org/html/2402.18563v1) | 表5同一消融框架下，无微调但有检索的Brier为0.186，无微调且无检索为0.206；全系统0.179。表4全题集人群为0.149，仍优于全系统。作者还发现额外的常规校准未改善其系统 | 优先验证有效检索，不把推理提示词或复杂度当增益。全文成绩含多种优化，不能全归因于一个步骤；这是历史模型与题集的结果 |
| A：[AIA Forecaster，2025，v1，表8–11](https://arxiv.org/html/2511.07678v1) | 已结局的64个实时市场中，有搜索/无搜索Brier为0.1002/0.3609；未结局部分对市场价格评分，不能视为真实结果。FB-7-21简单均值为0.1140，普通协调模型0.1168，主动检索分歧的协调模型0.1125；不同表的无聚合口径不完全一致。表11校准在该设置有收益 | 将有效检索、简单聚合、查证分歧分开消融；不复制10次调用或固定极化参数。论文不能证明普通多角色讨论必然更强 |
| A：[Mellers等，2014，作者机构全文](https://faculty.wharton.upenn.edu/wp-content/uploads/2015/07/2014---psychological-strategies-for-winning-a-tournament.pdf) | 两年地缘政治赛事中的训练、协作与跟踪实验支持概率训练和团队机制；训练涉及参照类、组合估计、避免过度自信和忽视基础率 | 转化为可检查的方法步骤，而非提示词“扮演超级预测家”。人类团队的行为结果不能直接等同于同模型复制多个角色 |
| B：[Zhang与Choi，2023，v1，第2、5–6节](https://arxiv.org/html/2311.09469v1) | 在问答、翻译和自然语言推断中，选择哪些样本澄清与利用答案是不同能力；有限交互预算下，选择性澄清优于随机分配 | 要测回答前后的判断变化，不只数问题。未证明未来事件预测收益，模拟回答也不代表真实用户行为 |
| B：[Dong等，2026，v1，第4–6节](https://arxiv.org/html/2601.06407v1) | 用信息价值权衡交互收益和成本；实现依赖模型估计意图、答案概率及后验，实验任务与开放未来预测不同 | 采用“问题应改变判断”的原则；缺少可信权重时不计算貌似精确的VOI分数，不新增高成本模拟用户链 |
| C：[Hyndman与Athanasopoulos，判断预测，第6.2、6.7节](https://otexts.com/fpp3/judgmental.html) | 有适用数据时以统计方法起步，结构化记录判断依据，谨慎进行主观调整 | 基础率和当前机制分别保存；历史生成过程已变化时不能机械沿用 |
| C：[预测组合，第13.4节](https://otexts.com/fpp3/practical.html) | 简单组合是值得认真比较的基线，复杂权重不天然更可靠 | 候选先比较单次与等权聚合；时间序列结论不能直接当事件概率效果证明 |
| C：[Paleka等，2025，v1，第2–3节](https://arxiv.org/html/2506.00723v1) | 指出历史回测的逻辑泄漏、日期受限搜索泄漏、模型截止声明不可靠、人类预测污染及分布外推问题 | 控制证据时点，隔离答案，按事件分组；最终以未结局问题的预先冻结为准。模型“忘记未来”的提示不能消除训练记忆 |
| A/资源：[ForecastBench论文](https://arxiv.org/abs/2409.19839)、[官方方法](https://www.forecastbench.org/about/)、[公开数据](https://www.forecastbench.org/datasets/index.html) | 提供动态未来问题、结果和人类预测资料；官方当前说明含最短7天的部分数据题 | 无用户也能选题并提前提交本地冻结。公共题库覆盖不等于私人经营、个人处境覆盖；外部正式提交另需明确操作授权 |

上述机制之间可能互相抵消。例如，多取材料可能带来噪声；额外校准在不同系统中的结果不同。因此优先级是本项目基于证据的选择，不是把多篇论文的收益相加。

## 2. 可用公开资源与本次实际检查

### ForecastBench

官方仓库：[forecastbench-datasets](https://github.com/forecastingresearch/forecastbench-datasets)。仓库许可为CC BY-SA 4.0；引用、再分发及衍生数据应保留来源和许可，不自动套用本仓库代码许可。

本次通过GitHub API取得提交 `027ba0b3017a60e0e64602d724284ac6b2d91134`（提交时间2026-10-29 07:30:17 UTC）。随后直接读取该提交的[2024-07-21专家个人预测JSON](https://github.com/forecastingresearch/forecastbench-datasets/blob/027ba0b3017a60e0e64602d724284ac6b2d91134/datasets/forecast_sets/2024-07-21/2024-07-21.ForecastBench.human_super_individual.json)，成功解析4,595,808字节、7,693条预测记录。顶层含 `organization/model/question_set/forecast_due_date/forecasts`；记录含 `id/source/forecast/resolution_date/user_id` 等字段。此数目不是独立问题数或已核验样本量。

这次只检查获取与结构，没有配对结果、复算论文成绩、训练校准器或运行本项目预测；文件未导入生产数据库。目录API访问曾因TLS连接中断失败，改用已知且固定提交的原始文件地址成功，未放松TLS验证。作者库页面另有429，采用作者机构PDF读取。

后续导入按 `(source, id, resolution_date)` 核对问题与结果，不能仅按id合并；核对实际数据契约后决定最终键。保留个体预测而非只取群体均值，可研究聚合与相关性，但人类概率不能作为本项目模型校准的训练对。校准必须用待部署流程自身生成的、与真实结果配对的概率。

### BTF-2候选资源

发布方[数据说明](https://futuresearch.ai/btf2-dataset-release/)称其公开1,417个二元问题及事前研究材料，并同时包含结局、预测与理由。页面及字段说明已读取，数据文件和许可尚未逐项审查，因此仅列为候选，不宣称已接入或独立确认其全部防泄漏性质。

如采用，原始文件不直接传给模型。仅按白名单抽取问题、规则和审计合格的事前材料；隔离结局、结局解释、他人预测、预测理由及含答案暗示的字段。发布方表示完整RetroSearch访问需申请；本轮未联系任何第三方。事前研究材料能降低检索泄漏，仍不能排除当前模型的训练记忆。

## 3. 实验结论如何迁移

必须依次回答：任务是否同类、当前模型是否同类、输入资料是否同等可见、预算是否可比、结论是否来自消融、数据时点是否可信、增益是否在共同问题集上成立。

本次能支持的结论是“选择这些机制作为候选比盲目堆步骤更有依据”。不能推出跨领域成功率、指定模型必胜、论文数值相加后的预期提升或某个固定校准系数适合生产。
