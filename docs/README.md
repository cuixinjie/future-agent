## 如何维护

- 修改功能时更新对应的现行页面；不为同一主题再建一份“新版”“补记版”使用文档。
- 当前状态只在开发计划登记；具体检查结果与重要变化写入[CHANGELOG](../CHANGELOG.md)。历史测试数量不复制为当前质量承诺。
- Schema、提示词、方法和迁移版本有兼容意义，保留并集中说明；文档本身以Git历史追踪修改。
- 历史记录保留日期和当时结论，迁移时修正链接。需要追溯再从归档索引进入。
- 当前说明以本分支代码为准，可能包含尚未发布的修复；发布版本的原始状态查对应发布说明。
