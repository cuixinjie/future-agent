## 实际项目结构

```text
README.md                 安装及普通使用入口
AGENTS.md                 AI 开发执行入口
CHANGELOG.md              重要变更与实际验证记录
docs/
  01–05                   当前设计、开发规范及计划
  guides/                 操作手册
  decisions/              设计决策和兼容边界
  reference/              阶段契约、迁移及高级/旧实验参考
  archive/                带日期的历史验收
src/future_agent/
  cli.py                  分步命令、配置读取与组合装配
  chat.py                 普通/高级终端交互
  config.py               配置边界
  application/            编排、预算、应用用例及端口
  domain/                 对象、版本、不变量和纯规则
  prompts/                读取、规划、提取、预测的版本化提示词
  providers/              模型、资料、搜索与网页适配器
  forecasting/            确定性报告渲染
  storage/                SQLite、文件快照、报告文件及 Alembic 迁移
tests/                    单元、集成及显式证据夹具
examples/                 人工离线示例、手工输入与协议夹具
deploy/searxng/           可选本地搜索部署
```

API/UI、案例比较和通用统计估计器尚未创建；实验职责目前位于 `application/evaluation*.py` 与 `domain/evaluation.py`，无需预建同名顶层目录。逻辑职责与文件名不要求一一对应。

## 保留与清理规则

- `examples/m1_offline.py` 与 `event.txt` 验证人工离线读取；`forecast-spec.json` 是旧人工结果定义输入；两份 `protocol*.fixture.json` 分别服务基础协议及 T11 夹具，均仍有用途。
- `tests/fixtures/`、旧提示词和 `storage/migrations/versions/0001–0006` 用于回归、旧协议及升级，不按“新版不直接调用”删除。
- `.env`、`data/`、`.venv/`、`dist/`、缓存等已被 Git 忽略；配置和数据必须保留。构建包/缓存可再生成，清理时限定明确路径并避开用户数据。
- 当前设计和使用规则变更应同步入口；真实运行记录按日期保留，不能用新结论覆盖旧验收。仓库内链接在搬移时同步，外部旧书签需使用本导航查找。

- [2026-10-29 真实链路复验](reference/15-R06真实链路复验-2026-10-29.md)：独立试运行的正文获取、引用抽查、预算和限制。
