## 数据在哪里

- SQLite保存会话、不可覆盖的事件版本、评估、预测、冻结、核验及实验记录。
- 正文快照保存在DATA_DIR内，保存原始和规范化文本及哈希；相同正文可共享文件，来源仍分别保留。
- 导出位于`DATA_DIR/reports/<随机ID>/`，包含Markdown、JSON和完整写入标记。
- 数据目录、数据库、配置和缓存不纳入Git；完整导出也不等于已匿名化。

报告JSON保留问题、定义、判断、概率、限制、引文、版本和必要来源信息，排除完整原文、整页缓存及服务配置。冻结哈希针对数据库中的完整冻结对象，不是裁剪后的报告JSON。

## 升级与回退

1. 停止使用该数据目录的进程。
2. 备份完整DATA_DIR，包含数据库和正文/报告文件；保留配置但不要公开密钥。
3. 按目标软件版本安装锁定依赖，启动时执行适用迁移。
4. 先检查已有会话、报告和冻结记录；回退使用升级前的完整备份。

禁止通过删除迁移、清库、覆盖历史或修改Schema字符串来模拟升级/回退。历史预测和冻结不因文档整理而改变；旧协议不自动解释为新版方法。细节追溯见[历史归档](../archive/README.md)。

### 2026-11-03 阅读与研究增量

阅读提示词升级至 `evidence-reading-1.4`，输入改为带原文偏移的多片段 `passages`；EvidenceReading 新增可选 `source_relationships`、`coverage_gaps`，缺省为空，旧记录不回填已审查。新版本可读旧记录；旧程序可能拒绝包含新增字段的记录，回退须恢复升级前 DATA_DIR 备份。无数据库迁移、依赖变化，旧冻结预测和旧实验算法不变。首轮页面预留、多片段筛选和阅读指令改变普通研究流程，比较实验必须记录本次代码及提示词版本，不能混作旧方法成绩。


### 2026-11-03 最终交付选择与审查
