# 当前实现与运行规则

本文描述本分支已实现的行为；模块位置见[架构](02-架构文档.md)，待实现工作见[开发计划](05-开发计划.md)。不在这里维护未来API草案或重复历史验收记录。

## 1. 配置

配置由[Settings](../src/future_agent/config.py)加载，进程环境变量覆盖选定的`.env`文件。全局参数`--env-file`选择文件，`--no-env`只禁用文件读取，仍读取进程环境；`--data-dir`指定本地数据目录。

| 环境变量 | 默认值/要求 |
|---|---|
| `LLM_PROVIDER` | `compatible` |
| `LLM_BASE_URL`、`LLM_MODEL` | 模型操作前必须配置；端点使用`chat/completions` |
| `LLM_API_KEY` | 默认空，是否必需由服务决定 |
| `LLM_STRUCTURED_MODE` | `text_json`；可显式选择`json_schema`，不静默切换 |
| `LLM_CONNECT_TIMEOUT` | 10秒 |
| `LLM_OUTPUT_TOKENS` | 4000 |
| `MAX_LLM_CALLS` | 每会话12次，含修复和重试 |
| `MAX_RUN_SECONDS` | 每会话600秒累计执行预算 |
| `MAX_CONTEXT_CHARS` | 60000字符 |
| `MAX_TOTAL_TOKENS` | 1000000；中断未知用量可能按预留计入 |
| `SEARCH_PROVIDER`、`SEARCH_BASE_URL` | `searxng`，地址默认未配置；须支持JSON输出 |
| `MAX_SEARCH_QUERIES`、`MAX_PAGES` | 每会话8次搜索、16次页面尝试，含重试 |
| `DATA_DIR` | `data` |
| `DATABASE_URL` | 未填时为`DATA_DIR/app.db`；只支持批准目录内SQLite文件 |

服务地址不能含内嵌凭据、查询参数或片段。模型、本地搜索与外部网页通道独立验证；模型可用不代表搜索或网页可用。

## 2. 目标与澄清

Reader只提取原文，不补事实或期限。目标规划保留已有明确问题、窗口和核验规则；未指定期限时提出适合问题的默认值并标明假设，相对窗口最长3660天。

一个分析聚焦主要目标；可以同时发生的多个指标不能强塞互斥结果。区分既定路径、行动条件与开放探索。

整个普通会话最多一轮三个澄清问题，目标阶段与研究后共享额度。问题须说明怎样影响判断以及为何不能自行调查。达到额度后不再追问，按已有资料交付或说明无法判断；必要性的语义质量仍依赖模型。

实际回答会产生新事件并重新规划。研究后回车跳过私人问题，且来源、事件和研究版本未变时，直接复用研究并保存未知影响。目标歧义或版本变化不适用此快捷路径。

## 3. 有界研究与证据

初始计划最多4条公开查询，首次最多执行2条。整个分析至多2轮研究；补充研究使用已授权剩余查询，或展示新查询并单独取得授权。私人叙述不直接作为搜索词。

每轮最多6页、120秒；首轮在剩余页面配额大于1时最多使用其一半，为缺口驱动的第二轮保留页面，并为阅读与判断保留至少120秒；会话剩余配额优先。规划/阅读/最终判断共用模型预算，格式修复最多两次。

目标规划和补充研究查询校验失败时，反馈安全的字段位置、查询序号和具体规则；非法JSON、额外字段也提供修复提示，不回显模型返回值或未知字段名。公开查询每条最多120字符（含空格），限制同时写入生成Schema与提示词；程序拒绝网址、邮箱、电话、换行与控制字符。电话检测豁免完整有效的YYYY-MM-DD日期和1900–2199内的两个年份（空格或连字符分隔），不豁免长数字中的日期片段；这些格式检查不证明语义上无私人信息。持续失败仍停止执行，不截断、不丢弃非法查询，也不增加修复预算。

正文每页最多4000字符、合计24000字符，通过目标词项选择至多三个不重叠原文片段，无匹配时回退正文开头。裁剪必须记录；词项匹配不证明材料相关或完整。

模型提供候选精确引文和相关性解释。程序检查文档归属、可见片段及完整正文中的唯一匹配，再保存位置。搜索片段、抓取失败或未读部分不能变成引用；多来源或合法引用不等于证据充分。

网页逐跳检查DNS、公网地址、TLS、大小、超时和类型。显式本地搜索服务不放宽外部网页规则。

## 4. 时点与版本

时间保存带时区、内部归一化UTC。普通流程先研究再固定证据截止Tc；相对预测窗口从剩余生成预算加1秒之后开始，准确时间显示在报告。提交超过窗口起点会被拒绝，绝对窗口已经开始时不悄悄移动。

证据资格检查获取、本地入库及快照完整性，旧发布日期不能掩盖截止后获取。关联到新事件版本保留原时间和来源关系。

目标、窗口或规则变化产生新事件版本并使相关下游产物失效。旧预测保留；冻结内容不可原位覆盖，修订另存并检查目标一致性。

## 5. 方法与交付

普通评估使用NumericBasis的参照、适用性、未知和限制；外部依据需要合格正文引用，自述依据需要原文陈述。未知不直接否决数值，但依据不足时不能强制给概率。

可交付概率、方向、条件、探索或无法判断。连续目标目前不提供通用数值分布。人工分步路径默认无概率情景，显式申请数值仍需资格通过。

程序检查结果定义、概率类型/范围、互斥穷尽总和、排序和主结果。仅允许1e-6内的舍入归一化并记录原值；非法值不静默裁剪。所有数值判断均未经独立校准。

报告从保存的Forecast渲染，不创造事实或概率。首屏显示问题、窗口、交付与主判断，有数字时显示已有主观概率；完整依据、假设、未知、反证与改判条件继续保留。

## 6. 失败、中断与导出

| 情况 | 行为 |
|---|---|
| 无法定义目标 | 保存具体原因，不创建假预测 |
| 模型超时或结构/规则校验持续失败 | 保存执行失败，不转换成空成功结果 |
| 未授权/未配置搜索 | 明确无检索限制，评估已有资料是否可用 |
| 已授权研究失败且无可用判断依据 | 保留执行未完成，不能用泛化回答掩盖通道故障 |
| 预算耗尽 | 停止调用，保留已有有效产物和失败原因 |
| 调用中断 | 记录费用未知，显式恢复或取消；重试不重置预算 |

报告导出目录不覆盖、不得通过目录链接越界；完整写入后才创建COMPLETE标记。导出排除完整原文、整页缓存和服务配置，但问题与引用仍可能含隐私。字段和兼容规则见[数据与版本](reference/数据与版本.md)。

## 7. 已实现的实验工具

预登记协议后保存全部项目×A/B/C条目，封存共同输入、历史正文、C输入和准备成本。A按12个完整30天窗口计算稳定发布频率；历史不全则保留缺失。B为同模型一次结构化直接预测；C使用指定版本评估和预测产物。新版协议可封存2.0结果定义，旧协议与旧方法保持隔离。

首次产物、迟交、取消、失败和缺失都保留。结果采用共同人工核验；完整窗口结束前不做整批评分。二元Brier为`mean((p-y)^2)`，报告配对差异、共同子集、覆盖/交付类型与成本。没有概率不填0.5。

现有工具不证明完整系统优于同模型可追问/搜索助手；等预算强对照、公开题库和校准实验仍未实现。真实前瞻成绩尚不存在。操作见[分步CLI](guides/分步CLI.md)。

## 8. 本地 Web 研究体验补强

分析任务支持协作式停止：规划、阅读、研究在步骤边界检查请求，最终预测复用取消步骤并丢弃迟到结果。无法保证立即终止供应商请求，已消耗及未知用量保留；停止后可显式重试。任务停止标记仅存于进程内，重启后沿用已有中断恢复规则。

进度显示取得正文数、记录剩余调用与时间预算、已保存缺口。取得正文不代表模型已读完；进行中的调用可能已预留预算。报告首屏展示已有关键驱动、未知和改判条件的首项，不新增判断。侧栏列出当前会话所关联冻结预测中已到期且未核实/作废的记录，争议记录继续保留，不后台自动核验。

阅读产物可选保存模型识别的共同原始来源关系及目标覆盖缺口；文档归属由程序检查，关系与覆盖的语义仍未经独立核实。不同域名不证明独立；缺口和共同来源警告进入后续评估与报告限制。引文必须在单个可见片段中及完整快照内各唯一匹配，不跨片段拼接。


## 9. 普通判断交付审查（2026-11-03）

新生成的普通阅读使用 evidence-reading-1.5；阅读的 conditional_only 是建议，最终模型可在来源条件合格时重新考虑未校准主观概率。insufficient、无依据来源、缺少自述陈述或缺少外部合格引用仍不开放数值资格；允许尝试不等于必须给数字。评估使用 evidence-assessor-2.1，最终提示词/方法为 forecast-2.1 / judgment-2.1。保留旧阅读对应的旧评估与旧预测步骤，不自动升级已保存判断。

新版最终产物必须保存 decision_review：最强反面解释、交付依据及边界、条件分析的驱动分支。程序检查审查完整、条件分支至少两个不同项、不直接重复结果定义、不以“默认分支”等显式首选冒充条件分析，以及选定内部字段名不得进入用户判断文本。校验失败共享原两次修复及持久化预算，持续失败不创建预测。这些结构与文字检查不能证明语义正确，也不能识别所有换措辞的空泛分析；仍须独立抽查。

Markdown及Web报告展示保存的判断边界与反面解释，不新增推断。不增加固定模型调用或依赖；旧实验协议与方法不变，新方法尚未接入正式实验协议，不能混入旧批次。普通可计算发布参照已有下节开发入口，真实数据准入、自动语义审查及真实准确率验证仍待完成。


## 10. 历史参照数据库开发入口（2026-11-03）

`HISTORICAL_REFERENCE_ENABLED`默认false。启用后目标规划可提出有类型的同产品/通道候选，普通流程研究前查库、最终事件生成后纯本地重新检查，参照绑定进入预测步骤及产物，不改变模型调用预算或既有数值门槛。`reference` CLI支持受控采集、不可变导入、本地检查和独立诊断题库白名单投影。方法`release-reference-1.0`复用原12窗口算法，观察频率与最终主观概率分开保存和展示；没有数据、无适用性和读取失败分别保留。软件发布参照要求人工审查、至少360天完整历史、截止前实际获取及入库，以及历史锚点至目标起点不超过3601秒；过期不补负例，须重新采集审查。

参照本身不授予数值资格。新版参照方法/预测/步骤与旧实验隔离，恢复固定绑定，旧冻结不回填。仅明确静态诊断题包导入，不具备通用历史回放运行器或强对照。真实采集未通过公网地址检查，无合格真实参照或预测改善成绩。详见[历史参照数据库](guides/历史参照数据库.md)。

发布参照2026-11-04算法增量：`release-reference-1.2`保留原始k/12，同时由程序计算固定Beta(1,1)先验下的后验Beta(k+1,13-k)及后验预测概率(k+1)/14。先验、真实计数、后验和估计全部封存在可选bayesian_estimate中并检查一致性；缺失、失败及未准入不补估计。新预测使用judgment-reference-1.1/forecast-reference-1.1，旧参照继续旧提示词，不改旧实验A或冻结。统计参照假设窗口条件独立且机制不变，未经校准、不替代最终主观判断或放宽资格。详情及先验依据见[历史参照数据库](guides/历史参照数据库.md)。

## 11. 体育与政治案例先导（2026-11-04）

复用HISTORICAL_REFERENCE_ENABLED。目标规划可映射mens-world-cup-final-extra-time-1.0或us-election-party-retention-1.0，必须保存目标届次。仅对相应二元既定路径目标提供定性参照，参照本身不开放数值资格。当前预测查询要求资料实际获取和入库均不晚于截止；按结果可知的保守上界排除未结局、同届和未来事件。缺失返回not_applicable，读取/完整性失败返回failed，不补概率。恢复使用步骤固定绑定，不读取新库替换原参照。

数据分开保存事前摘录、结果、官方正文快照、真实获取/入库时间和哈希。政治标签比较相邻届官方选举人团胜者党派；体育标签核对aet或完整正常时间进球记录。program_source_checked仅指程序来源/字段核对，不能冒充人工批准。资料为今天获取的历史事实重建，事前输入仅投影保守时间界限前的摘录，不含目标结果或现时整页正文。replay-input独立允许迟获取的历史诊断，不伪装成严格前瞻，不解除普通ForecastService对过去窗口的拒绝。

参照方法case-reference-1.0、预测方法judgment-case-reference-1.0、最终提示词forecast-case-reference-1.0；有案例绑定的新预测2.2、步骤1.2、报告导出1.3，规划参照提示词1.1。旧发布方法、旧冻结哈希及旧实验版本不回填。
