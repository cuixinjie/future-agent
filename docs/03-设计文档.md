# 当前实现与运行规则

本文描述本分支已实现的行为；模块位置见[架构](02-架构文档.md)，待实现工作见[开发计划](05-开发计划.md)。不在这里维护未来API草案或重复历史验收记录。

## 1. 配置

配置由[Settings](../src/future_agent/config.py)加载，进程环境变量覆盖选定的`.env`文件。全局参数`--env-file`选择文件，`--no-env`只禁用文件读取，仍读取进程环境；`--data-dir`指定本地数据目录。

| 环境变量 | 默认值/要求 |
|---|---|
| `LLM_PROVIDER` | `compatible` |
| `LLM_BASE_URL`、`LLM_MODEL` | 模型操作前必须配置；端点使用`chat/completions` |
| `LLM_API_KEY` | 默认空，是否必需由服务决定 |
| `LLM_STRUCTURED_MODE` | `text_json`；可显式选择`json_schema`，不静默切换 |
| `LLM_CONNECT_TIMEOUT` | 10秒 |
| `LLM_OUTPUT_TOKENS` | 4000 |
| `MAX_LLM_CALLS` | 每会话12次，含修复和重试 |
| `MAX_RUN_SECONDS` | 每会话600秒累计执行预算 |
| `MAX_CONTEXT_CHARS` | 60000字符 |
| `MAX_TOTAL_TOKENS` | 1000000；中断未知用量可能按预留计入 |
| `SEARCH_PROVIDER`、`SEARCH_BASE_URL` | `searxng`，地址默认未配置；须支持JSON输出 |
| `MAX_SEARCH_QUERIES`、`MAX_PAGES` | 每会话8次搜索、16次页面尝试，含重试 |
| `DATA_DIR` | `data` |
| `DATABASE_URL` | 未填时为`DATA_DIR/app.db`；只支持批准目录内SQLite文件 |

服务地址不能含内嵌凭据、查询参数或片段。模型、本地搜索与外部网页通道独立验证；模型可用不代表搜索或网页可用。

## 2. 目标与澄清

Reader只提取原文，不补事实或期限。目标规划保留已有明确问题、窗口和核验规则；未指定期限时提出适合问题的默认值并标明假设，相对窗口最长3660天。

一个分析聚焦主要目标；可以同时发生的多个指标不能强塞互斥结果。区分既定路径、行动条件与开放探索。

整个普通会话最多一轮三个澄清问题，目标阶段与研究后共享额度。问题须说明怎样影响判断以及为何不能自行调查。达到额度后不再追问，按已有资料交付或说明无法判断；必要性的语义质量仍依赖模型。

实际回答会产生新事件并重新规划。研究后回车跳过私人问题，且来源、事件和研究版本未变时，直接复用研究并保存未知影响。目标歧义或版本变化不适用此快捷路径。

## 3. 有界研究与证据

初始计划最多4条公开查询，首次最多执行2条。整个分析至多2轮研究；补充研究使用已授权剩余查询，或展示新查询并单独取得授权。私人叙述不直接作为搜索词。

每轮最多6页、120秒，并为阅读与判断保留至少120秒；会话剩余配额优先。规划/阅读/最终判断共用模型预算，格式修复最多两次。

目标规划和补充研究查询校验失败时，反馈安全的字段位置、查询序号和具体规则；非法JSON、额外字段也提供修复提示，不回显模型返回值或未知字段名。公开查询每条最多120字符（含空格），限制同时写入生成Schema与提示词；程序拒绝网址、邮箱、电话、换行与控制字符。电话检测豁免完整有效的YYYY-MM-DD日期和1900–2199内的两个年份（空格或连字符分隔），不豁免长数字中的日期片段；这些格式检查不证明语义上无私人信息。持续失败仍停止执行，不截断、不丢弃非法查询，也不增加修复预算。

正文每页最多4000字符、合计24000字符，通过目标词项选择连续片段，无匹配时回退正文开头。裁剪必须记录；词项匹配不证明材料相关或完整。

模型提供候选精确引文和相关性解释。程序检查文档归属、可见片段及完整正文中的唯一匹配，再保存位置。搜索片段、抓取失败或未读部分不能变成引用；多来源或合法引用不等于证据充分。

网页逐跳检查DNS、公网地址、TLS、大小、超时和类型。显式本地搜索服务不放宽外部网页规则。

## 4. 时点与版本

时间保存带时区、内部归一化UTC。普通流程先研究再固定证据截止Tc；相对预测窗口从剩余生成预算加1秒之后开始，准确时间显示在报告。提交超过窗口起点会被拒绝，绝对窗口已经开始时不悄悄移动。

证据资格检查获取、本地入库及快照完整性，旧发布日期不能掩盖截止后获取。关联到新事件版本保留原时间和来源关系。

目标、窗口或规则变化产生新事件版本并使相关下游产物失效。旧预测保留；冻结内容不可原位覆盖，修订另存并检查目标一致性。

## 5. 方法与交付

普通评估使用NumericBasis的参照、适用性、未知和限制；外部依据需要合格正文引用，自述依据需要原文陈述。未知不直接否决数值，但依据不足时不能强制给概率。

可交付概率、方向、条件、探索或无法判断。连续目标目前不提供通用数值分布。人工分步路径默认无概率情景，显式申请数值仍需资格通过。

程序检查结果定义、概率类型/范围、互斥穷尽总和、排序和主结果。仅允许1e-6内的舍入归一化并记录原值；非法值不静默裁剪。所有数值判断均未经独立校准。

报告从保存的Forecast渲染，不创造事实或概率。首屏显示问题、窗口、交付与主判断，有数字时显示已有主观概率；完整依据、假设、未知、反证与改判条件继续保留。

## 6. 失败、中断与导出

| 情况 | 行为 |
|---|---|
| 无法定义目标 | 保存具体原因，不创建假预测 |
| 模型超时或结构/规则校验持续失败 | 保存执行失败，不转换成空成功结果 |
| 未授权/未配置搜索 | 明确无检索限制，评估已有资料是否可用 |
| 已授权研究失败且无可用判断依据 | 保留执行未完成，不能用泛化回答掩盖通道故障 |
| 预算耗尽 | 停止调用，保留已有有效产物和失败原因 |
| 调用中断 | 记录费用未知，显式恢复或取消；重试不重置预算 |

报告导出目录不覆盖、不得通过目录链接越界；完整写入后才创建COMPLETE标记。导出排除完整原文、整页缓存和服务配置，但问题与引用仍可能含隐私。字段和兼容规则见[数据与版本](reference/数据与版本.md)。

## 7. 已实现的实验工具

预登记协议后保存全部项目×A/B/C条目，封存共同输入、历史正文、C输入和准备成本。A按12个完整30天窗口计算稳定发布频率；历史不全则保留缺失。B为同模型一次结构化直接预测；C使用指定版本评估和预测产物。新版协议可封存2.0结果定义，旧协议与旧方法保持隔离。

首次产物、迟交、取消、失败和缺失都保留。结果采用共同人工核验；完整窗口结束前不做整批评分。二元Brier为`mean((p-y)^2)`，报告配对差异、共同子集、覆盖/交付类型与成本。没有概率不填0.5。

现有工具不证明完整系统优于同模型可追问/搜索助手；等预算强对照、公开题库和校准实验仍未实现。真实前瞻成绩尚不存在。操作见[分步CLI](guides/分步CLI.md)。
